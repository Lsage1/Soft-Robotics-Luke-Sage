To generate plots for the beam bending run Homework2.py

This will output 2 plots, and optionally 3 plots. 
The code is set up to iterate over 20 -> 20,000N to predict beam bending at each load.
To evaluate at only one load value, set the variable loadCount = 1. 

To view plots of deformed beams, reduce the value of plotStep to 50.
